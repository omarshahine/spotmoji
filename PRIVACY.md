# Spotmoji Privacy

Spotmoji does not collect, transmit, sell, or share personal data.

The app uses these local macOS features:

- **Core Spotlight** stores the bundled Unicode emoji catalog in the local Spotlight index.
- **Pasteboard** temporarily holds the emoji you select.
- **Accessibility** restores the previously active app and sends Command-V. Search and copy continue to work without this permission.
- **Unified Logging** records local diagnostic messages about paste targeting. These stay in the Mac's system log and are not sent to OmarKnows LLC.

Spotmoji has no analytics SDK, advertising SDK, account system, cloud database, or network API.
